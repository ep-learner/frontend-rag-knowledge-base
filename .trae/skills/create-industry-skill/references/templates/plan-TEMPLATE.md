## 三、大量避坑：高 star 但不推荐的方案类型（必须写）

> 把符合 PRD 四·4「排除项」的、star 很高但实际不解决核心问题的，列出来告诉用户为什么不要选。**这能显著提升用户信任**。

【填 3~5 类，例】
- **高星食谱生成/宏量计算类（如 NourishAI、NutriGen、各种 meal-plan generator）**：
  - Star 可能 1k+，但核心能力是生成食谱、算卡路里，**没有证据溯源、没有置信分级、不区分证据质量、不给出验证路径**
  - 本质是格式化生成器，不能解决你「鉴别 AI 对错、信息驳杂」的核心诉求 → 完全排除
- **纯养生/中医养生类、带保健品带货导向的 Prompt**：
  - 绝大多数是普通 prompt，没有证据分级、证据质量不可控 → 不建议直接用
- **「你是一个资深 xx 专家」类普通 Prompt（无结构化约束）**：
  - Star 再高也没用，AI 还是会自由发挥、瞎编证据 → 完全排除

## 五、现成可直接用的最小版（如果用户不想装完整 Skill，直接复制这个系统 Prompt）

> 这里放一个能直接用的系统 Prompt，融合了最终推荐方案的核心约束，**让用户立刻就能用最小成本验证方案可行性**。

【填，例】
```
# Role: Evidence-Based {行业} Checker Skill（例：Evidence-Based Nutrition Checker Skill）
# Output Hard Constraints:
1. 分六段输出，禁止混写：
   - Conclusion：一句话结论
   - Evidence & Confidence：证据等级 Strong/Moderate/Low + 来源类型（中国xx指南 / RCT / Meta / 观察 / 体外动物 / 专家意见）+ 引用源
   - Actionable Plan：具体可执行方案（量化到 g/mg/时间）
   - Population & Boundary：适用人群、禁忌、RNI/UL剂量边界、药物交互
   - Verification Path：客观验证分三级（🏠居家可测 / 🩸医院化验 / ⚠️体感仅参考），明确时间节点
   - Keywords for Verification：3~5组中英文检索关键词 + 权威检索源白名单
2. 禁止编造文献；只有动物/细胞实验 → Confidence 强制 Low + 明确警告不能外推人体
3. 优先对齐【本土化指南，例：中国居民膳食指南2022】，冲突必须显式说明
4. 推荐补剂必须回答：优先食物吗？什么时候才值得补？复查什么指标？
5. 最后附：常见营销误区避坑 + 免责声明
```
