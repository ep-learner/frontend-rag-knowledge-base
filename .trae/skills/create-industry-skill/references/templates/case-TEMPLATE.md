# case 模板（⚠️ 必须由用户自己写！Agent 不代写。就按你真实会怎么问的口吻写，不要「标准问法」）

> 2~3 个真实场景就够了。每个 case 要覆盖不同类型的问题，不要重复。
>
> **为什么你要自己写？** Agent 编的 case 默认会假设你提问时信息非常完备、用专业术语，测出来的 Skill 在真实场景下你用口语一问就崩。你自己写的才是真实使用场景，测出来的 Skill 才好用。

---

## case1（一个类型的问题）

**用户画像**：【填，越真实越好】例：28岁男性，互联网上班族，作息饮食不规律，几乎不点餐不做饭，成年后完全没学过营养学相关知识
**问题原文**（【⚠️ 就写你真实会说的话，不要补你不会说的信息】）：
【填，例】
「最近因为工作原因经常熬夜，吃饭也不规律，下午老是觉得疲惫想睡觉，咖啡喝多了晚上更睡不着。想通过日常饮食改善一下个人状态，我应该从哪下手？」

（注意：**不要自己加你真实问的时候不会说的信息**，比如不要主动说「我的身高体重是XX」「我没有疾病史」——真实世界你问 AI 不会主动说这些，Skill 应该会自己追问缺失信息，而不是假设）

## case2（另一个类型的问题，和 case1 不要重复）

**用户画像**：【填，和 case1 不一样或同一个人但另一种场景】例：25岁男性，平时不怎么运动，国庆出去旅游暴走了3万步
**问题原文**：
【填，例】
「国庆出去玩暴走了3万步，隔一天开始半月板疼，去医院扫描了说没啥结构问题，医生就说以后避免突然暴走。日常也几乎没什么感觉。但是我想知道是不是缺钙了？需要买钙片或者氨糖吃吗？平时喝牛奶比较少。」

（刻意设计一个常见营销陷阱场景：AI 会不会告诉你「半月板疼=缺钙」？会不会主动指出常见骗局？这就是为什么要你自己写 case 的原因——你知道真实场景下最容易踩什么坑）
