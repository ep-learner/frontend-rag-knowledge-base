# originPrd 模板（【填这里】的地方替换成你的内容，其他结构保留）

> ⚠️ 本文件是唯一基准。后续所有 plan、准出、Skill、测试输出都以本 PRD 为准。改需求就改 PRD，不要口头说。

---

## 一、我的背景（用户是谁 + 痛点）

【填】我是谁？（例：28岁普通上班族，非医疗背景）
【填】我在这个领域目前的认知水平？（例：完全不懂，之前没系统学过营养学，网上信息大多是广告不知道信谁）
【填】最近遇到的具体困难/痛点？（例：同样的营养问题问了3个AI，回答全不一样，我不知道信谁；按AI建议吃了补剂1个月，不知道有没有效）

---

## 二、我要解决的核心问题（编号列，≥2个，用「怎么/如何」开头）

> 验收时会逐条查：**AI 输出有没有全部回答这些问题**。漏了就是不合格。

1. 【填】我的第一个核心问题？（例：我用什么方式能判断 AI 给我的营养建议是不是正确的？）
2. 【填】我的第二个核心问题？（例：按 AI 建议吃了补剂/改了饮食之后，除了体感之外，有什么客观检验方式？具体查什么项目？）
3. 【填】（可选，建议 2~5 个，不要太多）第三个核心问题？（例：GitHub 上有没有现成高 star 的营养师 Skill 或 Prompt 项目？要带证据链+验证方式的，不是纯生成食谱那种）

## 三、对最终产出物的要求（Agent 会补默认要求，你可以删改）

> 默认要求（**建议保留，这是解决「AI不可信」的核心约束**）：
> - 必须每条建议标「证据等级 Strong/Moderate/Low」+ 来源类型+出处
> - 必须给出「不靠体感的客观验证方式」（居家测什么、医院查什么，有时间节点）
> - 必须给出「二次查证检索关键词 3~5 组」+ 权威检索源白名单（不要百度直接搜）
> - 必须指出常见营销骗局/智商税
> - 方案必须量化（多少g/mg/多久，不要说「多吃点」「适量」）
> - 优先本土化对齐中国官方指南/标准（不要直接套欧美数据）

### 3.1 格式要求（你可以加）
【填】例：输出必须分 6 段，每段标题固定；不要太长，每个问题回答控制在 500 字内

### 3.2 证据要求（你可以加）
【填】例：所有针对中国健康成年人的结论，优先对齐《中国居民膳食指南2022》和中国 DRIs；如果引用欧美数据必须显式标注人群差异

### 3.3 验证要求（你可以加）
【填】例：必须分三级（居家 2~4 周 → 医院 1~3 个月 → 体感仅参考），每个级别明确「测什么、怎么测、看什么指标算有效」

### 3.4 避坑要求（你可以加）
【填】例：明确指出常见营销误区如「关节疼=缺钙」「胶原蛋白补皮肤」等是智商税

### 3.5 其他特殊要求（长度/语气/禁忌等）
【填】例：术语尽量通俗，假设我是小白；绝对禁止推荐没有科学依据的「排毒」「湿气」等概念

## 四、方案调研范围（告诉 Agent 搜什么、怎么筛）

> 按你这个领域改关键词和筛选标准，下面是营养行业的示例

### 4.1 搜索关键词（GitHub / 开源社区搜什么）
【填】例：GitHub 搜 `nutrition skill github star` / `diet prompt evidence-based` / `health coach skill` / `evidence-based nutrition prompt`

### 4.2 Star 筛选标准
【填】例：优先 ≥100 star 的项目；如果 star 低但证据链机制设计特别合理的也可以（比如只有 50 star 但明确写了 GRADE 分级）

### 4.3 必须满足的能力点（缺一个就不要）
【填】例：
- ① 必须强制结构化输出（有明确分段要求）
- ② 必须有证据分级/置信标注/引用溯源机制
- ③ 必须有验证路径/效果测量方式
- ④ 要有中国本土化适配（中国食物数据库/中国膳食指南优先）或设计了本土化改造空间

### 4.4 必须排除的方案类型（看都不用看）
【填】例：
- 纯食谱生成器/卡路里计算器（没有证据链，本质是格式化生成器）
- 没有明确输出格式约束的「你是一个 xx 专家」普通 Prompt
- 带保健品带货导向、没有证据分级的养生/中医类 Prompt
