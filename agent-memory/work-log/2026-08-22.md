#### Skill 核心能力（6段强制结构）

1. **【一、一句话结论】**：明确行动方向，禁止模棱两可
2. **【二、证据等级 & 来源】**：每条建议独立标 Strong/Moderate/Low
   - 本土化优先级：中国膳食指南2022 > 中国DRIs 2023 > 国际指南
   - 引用欧美数据必须显式标注
   - 绝对禁止编造文献
3. **【三、具体可执行方案】**：
   - 饮食：每餐量化（主食多少g、蛋白多少g、蔬果多少g）
   - 补剂四问：要不要补？补多少？补多久？什么剂型？
4. **【四、适用人群 & 禁忌边界】**：明确谁能用、谁慎用、谁不能用、药物交互
5. **【五、效果验证路径】**：三级验证（不靠体感）
   - 🏠 居家可测：第2周评估（精力评分、三餐打卡率、睡眠、静息心率等）
   - 🩸 医院化验：第4周评估（明确查什么项目、挂什么科、怎么看报告）
   - ⚠️ 体感仅参考，必须搭配客观指标
6. **【六、二次查证检索关键词】**：3~5组中英文关键词+权威检索源白名单
   - 推荐源：中国营养学会、国家卫健委、知网、PubMed、Cochrane Library
   - 避坑：禁止百度知道/小红书/知乎直接搜（广告>80%）

附加：常见误区避坑提醒 + 每次必带免责声明

#### Case 测试验证结果

**Case1（28岁男，作息饮食不规律易疲惫）核心输出要点**：
- 结论：疲惫大概率源于B族+隐性缺铁+血糖波动，不是肾虚湿气
- 优先级：先固定三餐（打卡率≥80%），2周后无改善再查血清铁蛋白+补剂
- 补剂：OTC药品级B族优先于保健品（2元=200元效果），补铁必须先查血清铁蛋白（不是血红蛋白！）
- 验证：居家第2周精力评分涨≥2分→有效；否则第4周去医院查4项血检（血常规+铁蛋白+VD+甲功）
- 检索关键词5组（覆盖规律三餐、隐性缺铁、B族、睡眠疲劳、OTC vs 保健品）

**Case2（25岁男，暴走后半月板疼是否缺钙）核心输出要点**：
- 结论：**半月板疼与缺钙无关**（解剖学明确：半月板是纤维软骨，不含钙；钙只管骨骼），不要被保健品营销骗
- 优先级：先RICE原则（休息+冰敷+加压+抬高72小时），补剂完全不需要现在吃
- 补钙条件：仅当你每天喝不到300ml奶+不吃豆制品时才需要补，且最多400mg/天（800mg是总摄入量，不是额外补的量）
- 氨糖/鱼油：仅当2周后仍疼再考虑，40%人无反应，吃8~12周无效就停
- 红线就医：关节锁死、打软腿、弹响+疼加重、1周无缓解
- 检索关键词6组（覆盖半月板解剖、突然运动损伤、RICE指南、氨糖Cochrane、中国DRI钙、胶原蛋白智商税）

#### 关键设计决策

| 决策 | 原因 |
|------|------|
| 三段证据分级+本土化优先 | 解决「AI说的对不对？是不是欧美数据直接套中国人？」用户原始诉求1 |
| 每一条建议必须量化（几克/多少mg/吃多久） | 解决「多吃点是吃多少？我不会做」落地难问题 |
| 三级验证路径（居家→医院，有时间节点） | 解决「我怎么知道有没有效？体感太主观了」用户原始诉求2 |
| 检索关键词+权威源白名单 | 解决「我想自己二次查证怎么搜？哪里搜不会搜到广告？」闭环需求 |
| 补剂默认「先食补2周不行再补」+补剂四问 | 防止盲目买一堆保健品（用户痛点：网上信息驳杂大多是广告）|
| 每条建议标注证据等级+具体出处类型 | 解决「信息驳杂，各说各的，我分不清谁对」 |
| 明确禁止编造文献+动物实验外推人体必须标Low | 防幻觉，这是本Skill和普通AI回答的核心区别 |

2. **三段式工作流详解**：
   - originPrd：4 要素+可复用模板（我的背景/核心问题≥2/产出要求/搜索范围），附营养师项目真实 originPrd 链接

3. **可信输出结构设计（6段强制）**：一句话结论→证据等级 Strong/Moderate/Low+来源→可执行量化方案→适用边界禁忌→三级客观验证路径（居家/医院/体感仅参考）→二次查证检索关键词+权威源白名单
4. **完整案例复盘**：营养师项目三个文件链接+方案选择过程（三个项目各取优点融合，不直接用任何一个）+最终 Skill 和 case 输出链接
5. **常见误区&坑点**：5 个坑（star越高越好/从零设计/模糊需求/体感算有效/直接百度自然语言）
6. **延伸阅读**：GRADE 分级 / Cochrane Handbook / PICO 框架
