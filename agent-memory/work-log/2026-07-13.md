## 关键决策

### 方案转向：从「AI 直接解析」到「插件提取 + 模板整理」
- 原因：豆包无法可靠解析视频链接，生成提示词让 AI 分析走不通
- 新流程：插件/工具提取原始内容 → 保存到 _pending → skill 调用 AI 按模板整理 → 写入正式目录
- 好处：流程可控、原始内容可追溯、模板可扩展
- 卡点：前端按钮无法直接触发 IDE 内的 AI 对话，需要用户手动调用 skill

### 工作台设计：左侧双区域 + 右侧模式切换
- 待整理（编辑）和已归档（预览）在同一个页面内完成闭环
- 不用再在「浏览笔记」和「工作台」之间切换
- 已归档区域用分类树展示，与浏览笔记逻辑一致
