## 关键决策

### 内容与展示分离
- 协议只管「怎么展示」，不管「写什么内容」
- .md 文件内容完全自由，协议只约束目录结构和 manifest 格式

### 文档分层原则
- 给人看的 → README.md、docs/、plans/README.md
- 给 agent 看的 → AGENT.md 系列
- 都看的 → ARCHITECTURE.md、CONTENT_PROTOCOL.md
- AGENT.md 只放导航 + 流程 + 原则，不放容易变的枚举

### plans 快速记录原则
- 听到「记个想法/以后再说/先记下来」 → 快速记到 plans/active/backlog.md
- 记完立刻回到主任务，不展开讨论、不追问细节
