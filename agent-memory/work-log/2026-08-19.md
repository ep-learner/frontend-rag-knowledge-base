# 2026-08-19 工作日志

## 今天做了什么

### 带娃工作台（baby-workbench）PWA 开发

- **触发**：用户想仿小红书链接做一个类似的育儿追踪工具
- **产出位置**：`plans/active/baby-workbench/`
- **技术栈**：纯静态 HTML/CSS/JS + PWA（无外部依赖，零构建）

#### 文件清单
| 文件 | 作用 |
|------|------|
| index.html | 8 Tab 移动端布局 |
| style.css | 响应式样式，Emoji + SVG 图标 |
| app.js | 数据常量 + 渲染 + 交互 + localStorage 持久化 |
| manifest.json | PWA 配置 |
| sw.js | Service Worker 离线缓存 |
| icon.svg | 婴儿车图标 |
| server.js | 本地 HTTP server（部署时不需要） |
| pe.md | 调度 PE（开发依据） |

#### 功能清单（8 大模块）
1. 首页数据总览：4 数据卡 + 7 天 SVG 趋势图
2. 今日任务：按本周主题自动生成 4 条
3. 每周主题：7 周轮换（颜色/水果/动物/身体/日常/数感/动作）
4. 活动库：35 条，双维度筛选（领域 × 主题）
5. 发育观察：6 大领域 × 5 条里程碑
6. 养育原则：5 核心 + 4 禁止
7. 教具清单：食物/DIY/进阶购买 3 类
8. 英文启蒙：SSS 儿歌 + 亲子口语 + TPR 指令，点按 TTS 发音

#### 关键决策
- **纯静态 vs React**：选纯 HTML/JS，零构建、零依赖、双击即用，部署到任何静态托管
- **数据持久化**：localStorage，导出 JSON 备份（无后端、无账户体系）
- **PWA**：加了三件套（manifest + sw + icon），localhost/https 下可完整生效
- **周数计算**：首次打开记录 startDate，每 7 天推进一周，7 周循环

#### 验证
- Node VM 沙盒验证全部数据完整性通过
- 浏览器代理确认 HTTP 200 加载、8 Tab 渲染、无 JS 错误

#### 后续可选
- 部署到 Cloudflare Pages/Vercel 获得公网链接 + 手机安装 APP
- 替换真实育儿数据（app.js 顶部常量）
- 加 PWA 后可推到主屏，iOS 独立存储不受 ITP 7 天清理影响

## 踩坑记录
- Python HTTP server 在沙盒里启动失败（端口冲突/编码问题），改用 Node 内联脚本启动成功
- 浏览器子代理在沙盒里能力受限：browser_evaluate 始终返回 null，snapshot 只显示交互元素
- PowerShell 不支持 `&&`，用 `;` 或 `Set-Location` 代替
