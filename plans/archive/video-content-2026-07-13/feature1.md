# 新Feature：BibiGPT 纯手动兜底模式迭代（彻底废弃API/前端自动解析）

## 1、核心现状结论

- BibiGPT 官方 API 已永久下线，**无任何自动化对接、二次开发、批量调用可能性**。

- 所有前端自动抓取、元数据解析、正则解析方案**全部废弃**，因其稳定性极差，不纳入技术方案。

- BibiGPT 仅可作为**人工网页工具**使用，无程序自动化能力。

## 2、本次迭代目标

清理所有失效、不稳定的自动化逻辑，将 BibiGPT 页面定位为**纯手动结果格式化兜底工具**，保证流程干净、稳定、可长期使用：

- 彻底删除：所有 API 调用、Token 配置、鉴权、前端自动解析、元数据抓取逻辑

- 保留唯一能力：用户手动粘贴 BibiGPT 网页版总结结果 → 页面一键标准化格式化

- 保持原有 RAG 输出规范不变，兼容现有落库流程

- 页面轻量化，无任何冗余失效代码

## 3、用户使用链路（最终稳定版）

**主力核心路线（日常99%使用）**：豆包批量提示词面板 → 全自动解析打分 → 复核落库（最稳、零成本、无依赖）

**BibiGPT 兜底路线（仅备用）**：用户手动打开 BibiGPT 网页 → 粘贴视频链接人工出总结 → 复制结果 → 粘贴进本页面 → 一键标准化格式化 → 复核落库

## 4、最终页面能力定义

本页面不再承担任何「视频内容解析、信息抓取」工作，只承担**结构化格式化**单一职责：

- 接收用户手动粘贴的任意 BibiGPT 原始总结文本

- 自动清洗杂乱格式、统一规整为 RAG 入库标准结构

- 输出固定结构：视频基础信息、时间戳知识点、代码片段、干货总结

- 支持一键复制、清空重置

## 5、废弃清理清单（Agent 强制执行）

- 删除所有 Token 输入、本地存储、API 鉴权、接口请求代码

- 删除所有前端跨域抓取、元数据解析、正则自动解析逻辑

- 删除所有 API 异常降级、loading 分支逻辑

- 移除所有与自动化解析相关的 UI 面板与状态提示

## 6、输出规范（完全沿用旧标准）

格式化输出严格匹配仓库 RAG 知识库入库规范，不改动字段结构：

- 视频基础信息（标题/作者/时长/源链接）

- 带时间戳核心知识点（按重要性降序）

- 可复用代码片段

- 整体干货总结

## 7、Agent 开发约束

- 纯静态 HTML/CSS/原生 JS，零后端、零第三方依赖

- 只做清理冗余 \+ 稳固手动格式化功能，不新增任何自动化解析逻辑

- 不修改原有主需求文档，仅增量迭代本 Feature

- 交付后页面干净、无报错、功能单一稳定
