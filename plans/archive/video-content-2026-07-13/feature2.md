# Feature2 迭代文档：B站链接标准化转换 + 本地可配置多PE提示词模板
## 文档说明
本文档为独立增量Feature，**不修改仓库原有基础需求文档**，仅针对【视频链接批量提示词生成面板】做功能迭代；全程无硬编码提示词，后续新增业务场景模板无需改代码、无需重新部署页面。

## 一、迭代背景
1. 原页面提示词固定写死在代码内，若需要切换理财、副业、置业、前端技术等不同场景解析话术，必须修改源码重新发布页面，维护成本极高。
2. B站原始链接携带大量冗余`vd_source`参数，豆包多模态解析时常失败，需要统一链接格式提升解析成功率。
3. 支持纯BV号直接录入，简化用户输入操作。

## 二、两大核心迭代目标
1. **B站链接自动归一化**：支持B站长链接、带参链接、纯BV号三种输入，自动提取BV字段，统一转为`https://b23.tv/BVxxxxxx`标准短链，剔除全部多余URL参数。
2. **本地持久化PE模板库**：基于浏览器`LocalStorage`存储多套自定义提示词模板，页面刷新自动加载；提供可视化面板新增/编辑/删除模板，下拉框选择生效模板，最终按固定协议拼接「模板内容+标准化链接」输出可直接复制的对话文本。

## 三、详细功能细则
### 3.1 B站链接标准化转换规则（仅针对B站链接）
| 用户输入内容 | 处理逻辑 | 最终统一输出格式 |
|------------|----------|------------------|
| B站长链接（含参数）`https://www.bilibili.com/video/BV1cANJzDE3S/?vd_source=xxx` | 正则提取BV编号，清除所有query参数 | `https://b23.tv/BV1cANJzDE3S` |
| 纯BV文本 `BV1cANJzDE3S` | 直接拼接标准域名 | `https://b23.tv/BV1cANJzDE3S` |
| 已为b23.tv短链 | 不做任何修改，直接沿用 | 原链接 |
| 抖音/小红书非B站链接 | 不执行转换逻辑，原样保留链接 | 用户原始输入链接 |

额外保留原有逻辑：非法格式链接标红提示，无法加入生成列表。

### 3.2 模板本地存储规范
1. LocalStorage 固定存储键名：`video_rag_prompt_templates`
2. 存储数据结构为JSON数组，单条模板结构：
```json
{
  "templateLabel": "下拉框展示名称（如：前端技术视频沉淀）",
  "templateContent": "完整PE提示词正文"
}
```
3. 数据仅保存在当前浏览器本地，不上传、不打包进页面代码、不提交Git仓库；更换浏览器需手动重新录入模板。

### 3.3 页面UI与交互新增能力
1. **模板选择下拉框**
页面初始化自动读取本地存储的模板数组，下拉列表展示`templateLabel`；若无任何模板，下拉框提示文字：`暂无模板，请先打开模板管理添加`。

2. **折叠式模板管理面板**
- 新增模板区域：两个输入框，分别填写【模板名称】、【模板完整提示词】，点击「新增保存」写入LocalStorage，下拉列表实时刷新。
- 已有模板列表：逐条展示模板名称+内容预览，每条配套**编辑**、**删除**按钮；编辑弹窗可修改名称与正文，删除直接移除本条模板，存储同步更新。

3. **彻底移除硬编码提示词**
删除页面内所有写死的解析Prompt文本，最终生成内容完全依赖用户选中的自定义模板。

### 3.4 固定输出拼接协议（不可改动）
对每一条校验通过、标准化后的链接，拼接格式如下：
```
{选中模板的 templateContent 全文}

待解析视频链接：{标准化之后的最终链接}
```
每条结果独立展示，支持**单条复制**；额外增加「批量复制全部结果」按钮，复制成功弹出极简提示。

### 3.5 原有存量功能100%保留
1. 输入框粘贴链接后按Enter键，自动录入下方链接列表并清空输入框；
2. 列表每条链接右侧带×删除按钮，可单独移除错误链接；
3. 链接格式校验、无效链接标红告警逻辑不变；
4. 页面技术栈维持**纯HTML+原生JS+CSS静态单文件**，无后端、无第三方依赖，本地双击即可打开运行。

## 四、边界约束
1. 本Feature仅修改「链接批量提示词生成面板」，另一BibiGPT格式化页面完全不改动；
2. 不新增任何打包、部署、后端接口相关逻辑；
3. 模板内容无长度强制限制，由浏览器存储容量天然约束。

## 五、交付要求
输出可直接本地打开的单HTML静态页面，控制台无报错，以下流程可完整走通：
录入链接→自动标准化→选择自定义模板→一键批量生成拼接文本→单条/批量复制；
可随时新增、编辑、删除提示词模板，刷新页面后模板数据不丢失。
