## 一、项目技术优化

### 1.1 数据库持久化改造（JSON → SQLite）

**现状**：向量库用 JSON 文件存储（`chroma-db/documents.json`），纯 JS 实现。

**问题**：
- 数据量大了之后读写可能变慢
- 不支持复杂查询
- 并发写入可能有问题

**当前判断**：目前只有十几篇笔记、几十个 chunks，JSON 完全够用。等内容涨到 100+ 篇、500+ chunks 再考虑，或者遇到性能瓶颈再说。

**待办**：
- [ ] 评估是否需要换成 SQLite（Prisma / Drizzle）
- [ ] 如果换，选 ORM 方案，迁移数据
- [ ] 对比：是自己写还是找现成方案

**优先级**：低（等遇到瓶颈再说）
