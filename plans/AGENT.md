# Plans Agent Guide

> 如果你是 AI Agent，要在 plans/ 目录下工作，请先读完本文档。
> 预计阅读时间：2 分钟。

---

## 这是什么地方

`plans/` 是**计划与想法管理区**，存放所有不在当前主任务流里的东西：
- 项目计划
- 突发想法
- 待办事项
- 分支探索
- 副业方向

**核心原则：记录在这里的东西，不要打断当前主任务。**

---

## 目录结构

```
plans/
├── AGENT.md              # 你正在看的
├── README.md             # 给人看的计划总览
├── active/               # ✨ 活跃想法（还没决定做不做，或准备做）
│   └── backlog.md        # 待办与想法收集（主入口）
└── archive/              # 📦 归档计划（已完成或放弃的）
    └── PROJECT_PLAN.md   # 旧的项目计划（已完成）
```

---

## 什么时候用这里

### ✅ 应该记到 plans/active/ 的情况

用户说这些话的时候，把想法记到 `plans/active/backlog.md`：
- "记个想法..." / "突然想到..."
- "这个以后再说" / "这个后面再做"
- "先记下来，现在不做"
- "有个方向可以探索一下"
- "副业方向/idea"

**怎么操作：**
1. 快速记到 `plans/active/backlog.md` 对应分类下
2. 记完立刻回到当前主任务
3. 不要展开讨论、不要追问细节、不要现在就做

### 📦 应该迁到 plans/archive/ 的情况

- 计划已经完成了
- 想法明确放弃了
- 项目做完了

**操作：** 把文件从 `active/` 移到 `archive/`，在文件顶部标记状态。

---

## backlog.md 维护规则

`plans/active/backlog.md` 是想法收集的主入口，结构：

```markdown
## 一、项目整理与优化
### 1.1 xxx
- 背景：...
- 待办：
  - [ ] xxx
- 优先级：低/中/高

## 二、学习与开发方向
...

## 三、副业方向探索
...

## 四、想法收集区
> 临时想到的、还没整理的想法，先丢在这里。
```

**维护原则：**
- 想到什么先丢「想法收集区」
- 定期整理（每周/每阶段），把收集区分到对应分类
- 不要让 backlog 变成垃圾堆，定期清理归档

---

## 重要提醒

|  | 说明 |
|--|------|
| ⚠️ **不要打断主任务** | 记想法是 10 秒的事，记完立刻回去 |
| ⚠️ **不要展开讨论** | 用户说"记一下"，就只记录，不分析、不建议、不追问 |
| ✅ **快速记录** | 能用一句话说清的，就别写三段 |
| ✅ **定期整理** | 主任务告一段落时，可以整理一下 backlog |

---

**一句话原则：快速记录，不打断主流程，定期整理。**
