# Archive - 降级归档区

> 这里存放低价值但不想删除的内容。内容保留，但不参与主 RAG 检索。

---

## 降级规则

### 什么时候降级？

| 情况 | 说明 |
|------|------|
| 内容过时 | 技术已经淘汰或更新换代 |
| 价值太低 | 学完发现内容太浅，没什么参考价值 |
| 重复内容 | 已有更好的同类内容 |
| 项目做完但参考价值不大 | Demo 跑通了，但代码和笔记都不值得保留 |

### 降级操作流程

1. 将内容从 `active/` 移动到 `archive/` 对应目录
2. 保持原目录结构不变
3. 在下方「降级记录」表格里登记

### 能不能恢复？

可以。随时可以从 archive 移回 active，叫做「升级」。
