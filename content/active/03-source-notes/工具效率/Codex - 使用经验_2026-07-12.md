## 工具简介

Codex 是一款桌面端 AI 辅助开发工具，可直接读写本地文件、操控浏览器和桌面应用，提供从对话、代码生成到完整项目开发的一站式工作流。

## 核心功能/亮点

1. **本地文件操作**：选择工作文件夹并设定权限模式后，AI 能自动扫描文件、生成清理报告甚至删除无用文件（实测一键回收 6.8GB 空间）
2. **计划模式与项目实战**：开启计划模式后 AI 会先生成方案、自行生成头像和代码，并在内置浏览器中预览，支持通过批注直接修改页面元素
3. **插件生态**：插件市场提供 Netlify 一键部署、表格处理、PPT 生成等能力，安装后通过 @调用即可使用
4. **Computer Use**：可让 AI 看到屏幕、移动鼠标点击，实现跨应用操作（仅限 macOS，消耗大量 token）
5. **Skills 机制**：将固定流程封装为技能包，支持安装社区技能（如动画制作、美化页面），也可用 Skill Creator 自动封装工作流
6. **三层记忆体系**：全局 AGENTS.MD、项目级 AGENTS.MD 和自动记忆，记录偏好与规则，减少重复说明
7. **Git 审核面板**：依托 Git 记录每次文件变更，支持逐块暂存、还原或提交，可直接推送至远程仓库创建 PR
8. **工作树模式**：允许多 Agent 并行修改而不冲突

## 踩坑记录

### 坑1：额度限制
- **问题描述**：有使用额度限制，按 5 小时和每周刷新
- **原因**：商业产品的计费机制
- **解决方法**：合理规划使用，生图、computer use 等操作消耗偏高，需谨慎使用

### 坑2：Computer Use 不稳定
- **问题描述**：AI 操控浏览器或软件偶有不稳定，某些应用对 agent 支持不足
- **原因**：技术局限性，不同应用的兼容性不同
- **解决方法**：优先使用终端命令和浏览器自动化完成操作，避免过度依赖 computer use

### 坑3：上下文溢出
- **问题描述**：长对话可能导致上下文溢出，任务质量下降
- **原因**：单次对话有效上下文约 258K token
- **解决方法**：在任务阶段后主动归档，或手动压缩上下文

## 适用场景

- 多 Agent 协作开发（工作树模式）
