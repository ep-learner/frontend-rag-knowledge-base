# n8n 工作流引擎学习

> 自托管可视化工作流编排引擎的架构分析与实践

---

## 项目简介

n8n 是一个**自托管的可视化工作流编排引擎**，核心是用**有向图执行模型 + 节点插件机制**，把各种外部 API、内部服务、AI 模型串成一条可执行的流水线。

本项目记录对 n8n 的架构学习和源码分析，重点借鉴其节点抽象模型、工作流执行引擎在 AI Agent 编排场景的应用思路。

## 学习重点

### 核心架构
- 节点的统一抽象模型（输入 → execute() → 输出）
- 基于有向图的工作流执行引擎（拓扑排序 + 数据流转）
- 配置驱动 UI 的节点参数系统

### 可借鉴设计
- 节点插件化设计思想
- 标准化数据结构（items 数组）
- 可视化编排 + 代码扩展的平衡
