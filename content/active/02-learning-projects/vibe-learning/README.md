# VibeVibe AI 编程学习项目

> 从零搭建 AI 编程助手的完整学习路径

---

## 项目简介

这是一个跟着 VibeVibe 教程，从零搭建前端 RAG 知识库 + AI 编程助手的完整学习项目。包含基础篇和进阶篇，记录了从 0 到 1 搭建整个系统的全过程。

## 学习路径

### 基础篇
- RAG 基础概念与原理
- 前端页面搭建
- 后端 API 开发
- 向量数据库集成

### 进阶篇
- API 规范化
- 测试分层与隔离
- 部署与安全
- 内容体系与知识管理
