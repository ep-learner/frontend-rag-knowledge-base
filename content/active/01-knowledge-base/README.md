# Knowledge Base - 知识点笔记

> 整理过的、高价值的纯知识点。RAG 主检索区。

---

## 这里放什么

- **纯知识点笔记**，不带 demo，不带项目代码
- 内容经过整理，价值密度高
- 是 RAG 检索的主要内容来源

---

## 分类方式

按技术领域建子目录，比如：
- TypeScript / React / 前端工程化 / 浏览器原理 / Node.js / ...
- 新增领域直接建目录，不用改任何配置

**命名规范**：`数字-领域名`（如 `01-TypeScript`），数字用于排序。

---

## 新增笔记

1. 确定分类，放到对应目录（没有就新建）
2. 复制模板：`../../templates/knowledge-note.md`
3. 文件名：`数字-标题.md`（如 `01-类型系统深度解析.md`）

---

## 升降级规则

- **升级**：来源整理（03-source-notes）里的内容整理后价值高，迁到这里
- **降级**：内容过时/价值降低，迁到 `../../archive/01-knowledge-base/` 对应目录
